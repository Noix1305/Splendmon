    📄 Cómo debe ser el archivo .json

    Un archivo .json con una lista "monsters". Cada Pokémon va entre { } y separado del siguiente por una coma. No lleva costos ni puntos: el juego los calcula solo, a partir de la cadena evolutiva y el peso.

    Campos
    
        
    
          
    CampoQué es
    
          
    nameobligatorioNombre del Pokémon.
    
          
    numrecomendadoNúmero de la Pokédex, como texto: "001". Sirve para unir las evoluciones.
    
          
    idopcionalNúmero para ordenar. Si falta, se usa num.
    
          
    typerecomendadoLista de tipos en inglés: ["Grass", "Poison"]. El primero decide qué pokebola da (ver «Pokebolas»). En pantalla se muestran en español.
    
          
    imgopcionalImagen: una dirección web o una ruta junto a index.html, como "img/001.png". Usa siempre /, nunca \. Sin imagen se ven las iniciales.
    
          
    height, weightopcionalTexto como "0.71 m" y "6.9 kg". El peso hace la carta más cara dentro de su nivel.
    
          
    weaknessesopcionalLista de tipos en inglés. Solo se muestra en la ficha.
    
          
    next_evolutionopcionalSus evoluciones: [{ "num": "002", "name": "Ivysaur" }]. Puede traer solo la siguiente o todas las que vienen después. Si un Pokémon tiene varias evoluciones posibles, van todas en la lista.
    
          
    legendaryopcionaltrue para los legendarios. Si ningún Pokémon lo trae, los 5 últimos sin evolución pasan a ser legendarios.
    
        
    
      
    
      
    
        
    Cómo se reparten en los mazos
    
        
    Primera etapa → Nivel 1 · segunda → Nivel 2 · tercera → Nivel 3 · sin evolución → Raros · "legendary": true → Legendarios.
    
        
    Errores comunes
    
        
      
          
    • Falta o sobra una coma entre dos Pokémon, o hay una coma después del último.
      • 
          
    • Rutas de Windows con \ (C:\Users\...): rompen el archivo. Usa /.
      • 
          
    • Comillas tipográficas (“ ”) en vez de comillas rectas (" ").
      • 
          
    • Todo debe ir dentro de { "monsters": [ ... ] }, empezando con {.
